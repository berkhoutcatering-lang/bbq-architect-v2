### Tool 23 — HACCP veldmode `/haccp/field` (tablet landscape primair)
Landscape tablet 1024×768. Header: "HACCP · Event {naam}" + offline-pill + Lars-naam. Hub-grid per CCP een grote card: "Vlees kerntemp" (laatst gelogd 67°C ✓) / "Koel-traject 4°C" / "Hete-buffet 60°C+" / "Reiniging post-event". Per card: big temp-input numpad-overlay 60px touch / tijd auto-prefill (now) / camera-button MediaDevices voor foto-evidence / "Log" CTA groot groen / history laatste 3 entries. Drie-tap log-flow: tap CCP-card → numpad → type temp + auto-tijd → optional camera → Log → tamper-save haccp_records. Anomaly-detect AI na save: toast "⚠ 52°C is laag — extend cooking?" met actie-chips "Extend 30min" / "Escalatie" / "OK". Corrective-actions verplicht bij anomaly met templates ("Doorgewarmd tot 65°C" / "Item afgekeurd" / "Smoker temp-recalibrated"). Mobile portrait fallback 375px: cards stack 1-koloms, numpad full-screen-overlay.
**Acceptance:** records tamper-evident (geen edit na 1u), foto verplicht voor critical CCP (vlees>57°C), AI is alleen suggestie nooit auto-corrective.
