# Copy-paste batches voor Claude.ai Design System

## Hoe te gebruiken

Per batch:

1. Open Claude.ai → **nieuwe chat** in BBQ Architect Design System project
2. Open het batch-bestand hier in Cursor / VS Code / Sublime
3. **Cmd+A** (alles selecteren) → **Cmd+C**
4. **Cmd+V** in Claude.ai chat-vak → Send
5. Claude bouwt → review canvas → Export ZIP → opslaan als `batch-N.zip`

## Tip

Tussen batches in: review wat Claude bouwde, schrijf in volgend bericht "Verbeter: [specifieke feedback]". Dan past 'ie dat patroon toe in de volgende batches automatisch.

## Als chat hangt of error gooit

Soms gebeurt bij grote batches. Doe:
1. Splits batch in 2 (e.g. eerste 4 tools / laatste 4)
2. Nieuwe chat per helft
3. Plak master-context opnieuw bovenaan
